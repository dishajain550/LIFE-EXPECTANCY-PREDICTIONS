# LIFE-EXPECTANCY-PREDICTIONS

# 🌍 Life Expectancy Prediction using Machine Learning

This project focuses on **analyzing global life expectancy trends** and building **regression models** to accurately predict life expectancy based on socio-economic and health indicators.

---

## 📌 Project Highlights

* Complete **Exploratory Data Analysis (EDA)**
* Missing Value Treatment using **Median Imputation**
* **Outlier Detection & Removal (IQR Method)**
* Feature Engineering & Label Encoding
* Multiple **Regression & Ensemble Models**
* Final **Model Performance Comparison using R² Score**

---

## 📊 Dataset Overview

* **Records:** 2900+
* **Features:** 22
* **Target Variable:** Life Expectancy
* **Key Attributes:** GDP, Mortality, Schooling, BMI, Alcohol Consumption, Population

---

## 🤖 Models Implemented

* Linear Regression
* Decision Tree Regressor
* Random Forest Regressor ✅ *(Best Model)*
* KNN Regressor
* SVR
* AdaBoost Regressor

🏆 **Best Performance:**
**Random Forest → R² Score = 0.959**
